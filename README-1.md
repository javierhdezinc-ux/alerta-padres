## Cómo probar la app

1. Entra → rol **Maestro** → un alumno → *No entró* o *Conducta*.
2. Cambia a **Padre** → Hoy. El aviso está ahí.
3. **En casa** → 3 pasos, temas, *Necesito ayuda ya* (siempre gratis).
4. **Dirección** ve quién abrió el aviso.
